## 🛠️ Recent builds

Paid product and AI engagements for multiple clients, built end to end.

- **AI pricing platform for a stablecoin trading desk, for a company moving $150M per month:** LLM parsing of unstructured liquidity-provider quotes into structured rates, a per-customer margin engine, mid-market guardrails that block off-market prices, and a full audit trail of every quote sent
- **Enterprise knowledge agent:** built on the Claude Agent SDK, source-cited answers that refuse when the knowledge is missing, weekly executive briefings, one agent across Slack, Teams, WhatsApp and email
- **OpenEvalOps:** LLM evaluation platform with live runs across OpenAI, Anthropic and Gemini, case-level diffs, nightly and PR-triggered regression checks
- **Business operating system:** 13 live modules replacing a SaaS suite for a mid-size business, behind role-based access control
- **Sales CRM and lead routing:** weighted round-robin in a database trigger, signature-verified webhooks, attribution and CAC/ROAS analytics
- **Property price and risk intelligence:** weekly pipeline over 7,400+ listings, and a geospatial platform fusing 7 signal layers with LLM extraction from news
- **GenAI risk engine:** led a team building a 4-stage LLM pipeline for institutional portfolios, with human review, escalation levels and a full audit trail
- **[MCP servers](https://github.com/ayoajuwon1/teams-mcp-server):** Microsoft Teams (15 tools via Graph) and Meta Graph API (Pages, Instagram, Ads, Messenger)
- **Survey automation:** Python package from raw beacon coordinates to subdivided layouts and survey-plan PDFs
- **Payments infrastructure for Webflow:** a Paystack integration with client-side and self-hosted modes, HMAC-SHA512 webhook verification, recurring subscriptions, and split payments across five currencies
